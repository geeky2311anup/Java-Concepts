# ☕ Java Concepts — Complete Reference Repository

This repository is a **comprehensive collection of Java concepts, programs, and notes**, covering both **core** and **advanced** Java topics.  
Each concept includes explanations and hands-on examples for better understanding and interview preparation.

---

## 🧠 Topics Covered

### 🏗️ Core Java
- Data Types, Variables, Operators  
- Control Statements (if-else, loops, switch)  
- Arrays and Strings  
- Methods, Recursion, Parameters  
- Input/Output using Scanner, BufferedReader  

### ⚙️ Object-Oriented Programming (OOPs)
- Classes and Objects  
- Constructors and Overloading  
- Inheritance and Polymorphism  
- Abstraction and Encapsulation  
- Interfaces and Abstract Classes  
- Static, Final, and Inner Classes  

### 🧩 Collections Framework
- List, Set, Map, Queue Interfaces  
- ArrayList, LinkedList, HashMap, TreeMap, HashSet, PriorityQueue  
- Generics, Iterators, and Streams API  
- Sorting using Comparable and Comparator  
- Utility classes in `java.util`  

### 🧵 Multithreading & Concurrency
- Thread creation and lifecycle  
- Runnable vs Thread  
- Synchronization and Locks  
- wait(), notify(), and notifyAll()  
- Executors, Thread Pools, Callable  
- Concurrent Collections  

### ⚡ Exception Handling
- try-catch-finally, throw, throws  
- Custom exceptions  
- Checked vs Unchecked exceptions  
- Common interview questions  

### 💾 File Handling & Serialization
- Reading and writing files using FileReader, BufferedReader, FileWriter  
- Object serialization and deserialization  
- Input/output streams and file management  

### 🧮 Advanced Java Concepts
- Lambda Expressions and Functional Interfaces  
- Stream API and Method References  
- Java 8+ Features (Optional, LocalDate, Default Methods)  
- Packages and Access Modifiers  
- Enums, Wrapper Classes, Autoboxing & Unboxing  

### 🌐 Miscellaneous
- Java Memory Model (Heap, Stack, GC)  
- Immutable Classes and Strings  
- Static vs Dynamic Binding  
- Command-line Arguments  
- Common Interview Patterns
